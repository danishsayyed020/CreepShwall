📊 CreepShwal E-commerce Sales Analysis (Excel Project)

This project focuses on analyzing an e-commerce dataset using Microsoft Excel. 
The goal was to clean raw data, perform analysis, and build interactive dashboards 
to extract meaningful business insights.

🔧 Tools Used:
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Cleaning Techniques
- Dashboard Design

📌 Key Steps Performed:
1. Data Cleaning
   - Removed duplicates
   - Handled missing values
   - Standardized columns

2. Data Transformation
   - Created new columns (Age Group, Month, etc.)
   - Structured dataset for analysis

3. Data Analysis
   - Gender-based sales analysis
   - Order status distribution
   - State-wise performance
   - Sales by channels (Amazon, Myntra, Ajio, etc.)
   - Age vs Gender insights

4. Dashboard Creation
   - Built interactive pivot dashboards
   - Visualized key KPIs and trends

📈 Key Insights:
- Women customers contribute higher sales compared to men
- Most orders are successfully delivered
- Certain states generate the highest revenue
- Online marketplaces like Amazon and Myntra dominate sales
- Adult age group contributes the most to purchases

📂 Files Included:
- Excel dataset
- Pivot tables
- Dashboard sheets

🚀 Outcome:
This project demonstrates how Excel can be used as a powerful tool 
for data analysis and business decision-making.
